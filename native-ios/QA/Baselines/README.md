# Protected screenshot baselines

Approved PNGs and JSON approval records are added here only through the explicit review procedure in `../README.md`. They are never overwritten by a test run. Each baseline is specific to screen, simulator size, theme, and state. Original reference sheets are design sources, not pixel-comparison baselines for a full simulator screenshot.

No simulator-derived image has been approved into this directory yet. The Daily Home UI test produces candidates for all 16 already-approved theme appearances.
