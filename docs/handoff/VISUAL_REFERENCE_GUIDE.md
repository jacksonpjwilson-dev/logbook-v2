# Visual reference map for Codex

## Source of truth and precedence

1. Read `DESIGN_AND_THEMES.md`, `FUNCTIONAL_REQUIREMENTS.md`, and the original 30-style design sheets in `VISUALS/01_ORIGINAL_USER_REFERENCES/`.
2. The **three IMG_2202/IMG_2203/IMG_2204 files** are the original visual reference sheets from the theme-selection conversation. These are the authoritative visual source; the approved selection is a subset of 16 from the 30 concepts.
3. `VISUALS/02_SUPPORTING_DESIGN_MOCKUPS/` holds supplementary generated exploration, UI concept boards, icons, and layout studies. These are NOT standalone evidence that a concept/theme was approved. Do not substitute designs from this folder for the user-approved 16.
4. Match the exact 16 names and identifiers in `DESIGN_AND_THEMES.md`. Preserve Premium Glass as the default. If an approved design cannot be uniquely matched to a panel, flag that particular match for review rather than guessing.
5. Treat the approved black rounded-square angular white L app icon as the final icon direction; other icon explorations in supporting references are non-binding.
6. Never confuse screenshot/mockup text, artificial performance numbers, or sample widgets with real user data.
